# npm_token_optimizer

[![CI](https://github.com/viveka10/npm_token_optimizer/actions/workflows/ci.yml/badge.svg)](https://github.com/viveka10/npm_token_optimizer/actions/workflows/ci.yml)

Source of the npm package **[@viveka10/cap-ai-token-optimizer](https://www.npmjs.com/package/@viveka10/cap-ai-token-optimizer)**,
a SAP CAP plugin that reduces, measures and reports SAP AI Core LLM token usage.

| Folder | What it is |
|---|---|
| [`cap-ai-token-optimizer/`](cap-ai-token-optimizer) | The npm package [`@viveka10/cap-ai-token-optimizer`](https://www.npmjs.com/package/@viveka10/cap-ai-token-optimizer): reduce, measure and report SAP AI Core token usage in SAP CAP Node.js apps. Start with its [README](cap-ai-token-optimizer/README.md). |
| [`sample-cap-agent/`](sample-cap-agent) | A small CAP app that uses the package, with a mock AI Core server for local development. |

CI and release workflows are in [`.github/workflows`](.github/workflows). See
[CONTRIBUTING.md](cap-ai-token-optimizer/CONTRIBUTING.md) for development and releases.
